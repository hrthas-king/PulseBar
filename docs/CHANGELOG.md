# 更新记录 (Changelog)

## v0.3.0 (2026-10-26)

- **新增全球 7 大市场标的分组切换与配置持久化**：
  - 右键菜单在“涨跌配色”与“刷新间隔”之间新增 7 组主流标的切换（单选勾选 `✔` 并持久化至 `config.json` 的 `market_group` 字段，点击后立即清空旧缓存并触发全量刷新）：
    1. `voo_qqq`（默认）：`标普 / 纳指 (VOO / QQQ)` —— 别名 `VOO`、`QQQ`
    2. `soxx_smh`：`半导体 ETF (SOXX / SMH)` —— 别名 `SOXX`、`SMH`
    3. `top2_us`：`美股市值前二 (NVDA / MSFT)` —— 别名 `NVDA`、`MSFT`
    4. `cn_indices`：`A股指数 (上证 / 创指)` —— 标的 `000001.SS`、`399006.SZ`，别名 `上证`、`创指`
    5. `hk_indices`：`港股指数 (恒指 / 恒科)` —— 标的 `^HSI`、`^HSTECH`，别名 `恒指`、`恒科`
    6. `asia_indices`：`日韩指数 (日经225 / 韩国综合)` —— 标的 `^N225`、`^KS11`，别名 `日经`、`韩指`
    7. `eu_indices`：`欧洲指数 (法国CAC / 德国DAX)` —— 标的 `^FCHI`、`^GDAXI`，别名 `CAC40`、`DAX`
  - 放宽底层行情校验以兼容 `ETF`、`EQUITY`、`INDEX` 及多国计价货币（`USD`、`CNY`、`HKD`、`JPY`、`KRW`、`EUR`），对含 `^` 的指数代码进行完整 URL 转义，并自适应扩展悬浮条槽位宽度（`228px`），确保五位数指数点位与涨跌幅不被截断。
- **升级五态交易时段状态信号灯**：
  - 悬浮条与详细诊断改用五态时段信号：☀️ 早盘/盘前（金黄 `☼` `RGB(255,193,7)`）、🟢 盘中（翠绿圆点 `RGB(0,230,118)`）、🔵 盘后（天蓝圆点 `RGB(56,189,248)`）、🌙 夜盘（月牙 `☾` `RGB(226,232,240)`）、⚪ 休市/周末（浅灰圆点 `RGB(148,163,184)`）。
  - 优先读取 Yahoo API `marketState` 字段，缺失时按交易所 `gmtOffSetMilliseconds` 本地时间自动推断；连续抓取异常时在信号右侧显示红色 `!` 提示。

## v0.2.2 (2026-10-26)

- **修复代理节点切换与 25 分钟 Crumb 刷新引发的行情红灯误报**：
  - 移除每 25 分钟强制重连 `fc.yahoo.com` 刷新 Crumb 的逻辑（保持长会话复用直至收到 `401`/`403`），并在代理/TUN 节点切换或连接异常时自动重建 WinHTTP 会话句柄。
  - 为行情状态机引入瞬时抖动容错：当已有 30 秒内新鲜缓存时，容忍 1~2 次瞬时网络/代理切换错误而不立即闪烁红灯；同时将失败退避上限从 60 秒缩短至 6 秒，并在代理节点或出口 IP 恢复时立即触发重拉。
  - 对扩展时段快速跳动时 `preMarketChangePercent` 的微小舍入偏差自动重算校准。

## v0.2.1 (2026-10-26)

- **修复夜盘/扩展时段实时性与涨跌幅基准，并同屏展示实时价格**：
  - 切换主行情源至带 `overnightPrice=true` 的 `/v7/finance/quote` 接口（WinHTTP 原生会话自动维护 Cookie 与 Crumb），直接获取 **Blue Ocean ATS (`BOATS Real Time Price`)** 的 `overnightMarketPrice`、`overnightMarketChange`、`overnightMarketChangePercent` 与 `overnightMarketTime` 实时成交时间戳。
  - 修复此前 `/v8/finance/chart` 在夜盘（`20:00–04:00 ET`）期间沿用两日前收盘价（`chartPreviousClose`）计算 `fulldayChangePercent` 导致涨跌幅失真的问题；现严格以最近一个常规交易日收盘价为基准计算夜盘/盘前/盘后涨跌幅。
  - 任务栏悬浮条直接同屏展示 **`实时成交价 + 涨跌幅`**（如 `VOO 699.48 +0.13% | QQQ 704.35 -0.01%`），使每 `$0.01` 的微小实时跳动都能在任务栏立即显现。
  - 悬停提示与诊断面板新增展示数据源名称（如 `BOATS Real Time Price`）与最近一笔交易所成交距今秒数（`最近成交 Xs 前`）。

## v0.2.0 (2026-10-25)

- **升级追踪 `VOO` 与 `QQQ` 24×5 全时段无缝实时行情**：
  - 将行情标的从延时 10 分钟的期货切换为 **`VOO`（Vanguard S&P 500 ETF）** 与 **`QQQ`（Invesco QQQ Trust）**。
  - 采用覆盖美东时间周日 20:00 至周五 20:00 全天 24 小时（**夜盘 Overnight 20:00–04:00 + 盘前 Pre-Market 04:00–09:30 + 盘中 Regular 09:30–16:00 + 盘后 Post-Market 16:00–20:00**）的 `fulldayPrice` 实时流，实现秒级跳动且无 10/15 分钟延时。
  - 悬停 Tooltip 与诊断面板新增当前交易时段自动识别（`夜盘` / `盘前` / `盘中` / `盘后` / `周末休市`）及常规盘收盘价对比。
  - 优化任务栏悬浮条三字母代码（`VOO` / `QQQ`）排版宽度，杜绝高 DPI 下文字拥挤。
