# 更新记录 (Changelog)

## v0.1.0 (2026-10-25)

- **全新双核整合**：将 **GeoPulse**（秒级网络连通性、上下行流量、出口 IP/国家监控）与 **TickBar**（TradingView `CME_MINI:ES1!` / `CME_MINI:NQ1!` 期货日涨跌幅监控）整合为单一纯 Go 原生应用 **PulseBar**。
- **任务栏悬浮条 + 系统托盘双视图**：
  - 任务栏最左侧默认显示：`[● 国家码 ↑↓ | ● ES 涨跌幅 | ● NQ 涨跌幅]`。
  - 支持右键菜单一键切换 **“任务栏显示实时网速与延迟”**，展开显示：`[● 国家码 ↑速率 ↓速率 RTT | ● ES 涨跌幅 | ● NQ 涨跌幅]`。
  - 系统托盘同步绘制 32×32 动态国家码、连通状态灯与上下行闪烁箭头。
  - 支持位置锁定（鼠标点击穿透）、自由拖拽保存位置、一键停靠任务栏最左侧、绿涨红跌 / 红涨绿跌配色切换、1s/2s/5s 刷新间隔与当前用户开机自启。
- **极致轻量化**：零第三方 Go 运行时依赖（`CGO_ENABLED=0`），完全基于 Win32 GDI、IP Helper API 与 WinHTTP 构建。
- **全新现代应用图标**：融合赛博蓝绿数字地球网格与上升脉冲 K 线波形的高清多尺寸图标资源。
